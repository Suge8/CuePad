# 界面文字与英文版

- 语言只由系统的应用语言偏好决定：不另存语言偏好、不运行时切换。键的例外只有 CloudKit 通知的 loc-key 与 Info.plist 的键（`InfoPlist.xcstrings`）。工程的开发语言（`DEVELOPMENT_LANGUAGE`）是英文：系统语言既不是中文也不是英文时回落到英文。
- 加字、改字：SwiftUI 的字面量（`Text("…")`、`Button("…")`）自动进目录；自定义视图收界面字的参数用 `LocalizedStringResource`，不用 `String`；模型层、Kit 算出来的界面字用 `String(localized: "…")`。整句带插值写成一个键，不拼碎片：英文语序不同。带数的句子在目录里给英文复数（one / other）。用户写的、Agent 说的内容原样显示（`Text(verbatim:)` 或 `String` 参数）。日期、时间、数字用系统格式化（跟随当前语言），不手写"分钟前""月日"。
- 确认框的"是""否"按答案种类存（`AnswerValue.shown`），不按字猜。能由存下的结构推出来的（提问的选项、没改过名的默认项目）只存结构或中文原值，显示时再写（`CueMessage.shownChoice`、`Project.shownName`）。共享快照同样只存项目原名，由小组件和分享扩展经 `Project.shownName` 按读取端语言显示，不把译名写入快照。
- 给 Agent 读的字不进目录：Cue 的系统提示、工具说明与工具结果、技能文件、`cuepad` 命令行、日志，以及只给 Cue 看的报错。它们是调过、评测过的中文，不另出英文版（两份就要两边一起调、一起评测）。同一句既上界面又给 Cue 看的，界面那份进目录。
- 演示库的内容（Debug 场景里写进库的标题、正文、对话）用 `String(localized: "…", table: "Demo")`：英文截图里出现中文就是漏翻。
- 改完跑 `xc.sh strings`，按它列出的缺英文的用 `strings.py set` 写英文（用法都在 `strings.py` 头注释）；`xc.sh check` 通过才算译完。
- 英文照下面「英文叫法」的叫法与大小写规则，地道、简短，Apple 风格（"…"表示还要再输入、快捷键写在括号里），不逐字直译；中文里为了说清楚加的字，英文能省就省。英文通常比中文宽一半到一倍：放字的地方不写死宽度，按钮、胶囊、列头在英文下照样不截断不换形，空间实在不够就换更短的说法，不缩字号。验收用英文截图（启动参数 `-AppleLanguages "(en)" -AppleLocale en_US`）。
- 能由字面量构成的类型（`ExpressibleByStringLiteral`）不给 `Text`、`Button`、`Label` 加不带标签的同名初始化器，非加不可就标 `@_disfavoredOverload`：否则 `Text("…")` 选中它，原样显示、不进目录。

## 英文叫法

英文界面只用这些叫法，没列的名词照 Apple 自家应用的说法。大小写只按字在界面上的位置定：导航与结构用 Title Case——页面与去处名、窗口与弹框标题（问句也是，"Forget This?"）、分段与标签页、列名、分组标题、按钮、菜单项、工具栏项、设置行的名字、空态标题；其余用句首大写——状态词与徽标（"Needs your OK"、"Not delivered"、"Not syncing"、"Running tool"）、说明、副标题、提示、帮助气泡、占位符、读屏标签与提示（同一个键也是按钮名时按按钮）、报错、横幅、通知正文、空态说明、复选框说明、斜杠命令的说明。下面的叫法作标题时 Title Case，嵌在句子与计数里小写（"3 need you"、"9 active"、"the agent session"）；Agent 不是专名，句中写 agent。一句里嵌状态词时状态词在句首（"Not syncing, can't answer now."）。同一个中文键在两种位置要不同大小写时拆键：改一处中文措辞或整句化，不在代码里改大小写。
